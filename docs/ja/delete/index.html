Samepaste のデータを削除する

更新日 2026-11-19

philaxis が作ったクリップボードアプリ Samepaste のデータを削除する方法です。Android のスマホ・タブレット版（Google Play）と Windows PC 版の両方が対象です。アプリが作ったデータを消す手順と、消したあとも残るものを書きました。

Samepaste には専用のアカウントがありません。登録もパスワードもなく、コピーした内容がサーバーに保存されることもありません。ただし Google でログインすると、アプリ内の接続サービス（Tailscale）にアカウントが 1 つ作られます。自分の端末どうしが見つけ合うためのもので、手順 3 で削除します。

削除の手順

  1. 各端末で履歴を消してログアウトする

    Samepaste の設定で「今すぐ消去」をタップし、「消去」で確定します。この端末の履歴が消え、写真から読み取った文字も一緒に消えます。続けて、設定の「Google アカウント」欄からログアウトします。

  2. アプリをアンインストールする

    スマホ、タブレット、PC のそれぞれから Samepaste をアンインストールします。アプリがその端末に残したものは、設定も含めてすべて消えます。

  3. 接続サービスのアカウントを削除する

    Tailscale の管理画面を開き、同じ Google アカウントでログインします。「Delete tailnet」を選び「Delete」で確定すると、Tailscale Inc. が端末の一覧、端末名、メールアドレスを削除します。あとで同じアカウントで Samepaste にログインすると、新しいアカウントが作られます。

  4. 残りはメールで依頼する

    ログインに使った Google アカウントを書いて、philaxis.dev@gmail.com にメールを送ってください。どのアドレスから送っても構いませんし、アプリがなくても大丈夫です。購入記録と、いただいたメールを削除してから返信します。

同じ Google アカウントで Tailscale をご自身でも使っている場合、「Delete tailnet」はそのネットワークごと削除します。その場合は Machines ページで、Samepaste を入れた端末だけを外してください。

削除されるもの

  • 端末の履歴と写真から読み取った文字：「今すぐ消去」を押すかアプリをアンインストールすると、その端末からすぐに消えます。
  • Tailscale Inc. が持つ端末名、メールアドレス、IP アドレス：tailnet を削除するとサーバーから消えます。Tailscale によると、診断ログやバックアップに残ったコピーも通常 60 日以内に消えます。
  • RevenueCat の購入記録：メールでご依頼いただければ削除します。
  • いただいたメール（このご依頼を含む）：返信したあとに削除します。ベータ特典のために残したメールアドレスは、コードを送ったあとに削除します。

残るものと保存期間

  • 利用統計とクラッシュレポート（送信を選んだ場合のみ）：ランダムな ID だけが付き、名前、メールアドレス、Google アカウントは含まれないため、特定の人の分だけを選んで消すことはできません。14 か月たつと自動で削除されます。
  • Google Play と Paddle の購入・税務記録：法律で決められた期間、両社が保存します。
  • コピーした内容：最初からサーバーに置かないので、消すものはありません。

詳しく

端末の外に出るものと受け取る相手は、すべてプライバシーポリシーに書いています。ご質問：philaxis.dev@gmail.com
