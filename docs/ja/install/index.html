オープンベータをインストール

Samepaste はいまオープンベータです。無料で、当面はストアではなくこのサイトからダウンロードします。Windows PC と Android のスマホやタブレットにインストールして、それぞれ同じ Google アカウントでログインしてください。

Windows PC

Windows 10 または 11

Windows 版をダウンロード
ファイル
Samepaste-0.8.0-beta.1.exe
SHA-256
643c44801da2eb895424561beaadf9f5133b7ae0b5dfa33b2e20540d6103fdbb

  1. インストーラーをダウンロード

    上のボタンからダウンロードします。ファイルはこのプロジェクトの GitHub のリリースから配布しています。

  2. SmartScreen を通過する

    ベータ版はまだコード署名をしていないため、「WindowsによってPCが保護されました」と表示されることがあります。「詳細情報」をクリックしてファイルが Samepaste であることを確かめ、「実行」をクリックします。

  3. インストールしてログイン

    インストーラーの案内に沿って進め、Google でログインします。

Android のスマホ・タブレット

Android 11 以降

Android APK をダウンロード
ファイル
Samepaste-0.8.0-beta.1.apk
SHA-256
5fa6e273afc4d0bdbc3ee435fbfec69b49cc401337b91479b229b03c391c7b90

  1. APK をダウンロード

    スマホかタブレットでこのページを開き、上のボタンからダウンロードします。

  2. ブラウザからのインストールを許可

    ダウンロードしたファイルを開きます。「提供元不明のアプリ」はインストールできないと表示されたら、「設定」をタップして「この提供元のアプリを許可」をオンにし、元の画面に戻ります。

  3. インストールしてログイン

    「インストール」をタップします。Google Play プロテクトが不明なアプリだと警告したら、そのままインストールを選びます。続けて、PC と同じ Google アカウントでログインします。

メニューの名前は、スマホのメーカーによって少しずつ違います。

ダウンロードしたファイルを確かめるには、SHA-256 を上の値と比べてください。Windows では PowerShell の Get-FileHash で確認できます。
