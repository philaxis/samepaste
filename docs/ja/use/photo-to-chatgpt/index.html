Samepaste使いみち

問題をスマホで撮って、ノートPC の ChatGPT に質問

問題は紙の上、ChatGPT はノートPC の中。そのあいだをいちばん短くつなぐのが、スマホのカメラです。

Android
カメラ
Windows ノートPC
ChatGPT
3番の解き方を教えて
CtrlV

流れ

  1. 写真を撮る

    いつものカメラアプリでそのまま撮ります。スクリーンショットでも同じです。

  2. ノートPC のクリップボードに入ります

    送信ボタンはありません。自動送信がオンなら、撮った写真が元の画質のまま全部の端末のクリップボードに届きます。

  3. ChatGPT に貼り付ける

    入力欄をクリックして Ctrl+V。聞きたいことを書いて送信しましょう。

必要なもの

  • スマホの Samepaste の通知で、写真のスイッチをオン
  • スマホとノートPC が同じ Google アカウント

Samepaste が見ているのはカメラとスクリーンショットのフォルダだけです。ほかのアプリが保存した画像は自動では送られません。
