Samepaste使いみち

スマホに届いた認証コードを、PC のログイン画面へ

ログインは PC なのに、認証コードはスマホに届く。あっちでコピーして、こっちで貼り付けましょう。

流れ

  1. スマホでコードをコピー

    SMS のコードを長押しして「コピー」をタップします。メッセージアプリがコードの横に出すコピーボタンでもかまいません。

  2. PC には自動で届きます

    Samepaste がコピーに気づいて、PC のクリップボードに入れます。基本の設定では数秒かかることがあります。設定で「完全自動」をオンにすると、コピーした瞬間に届きます。

  3. PC で Ctrl+V

    コードの入力欄をクリックして貼り付けるだけ。打ち直していないので、打ち間違いもありません。

必要なもの

  • Windows 10 か 11 の PC と Android 11 以降のスマホ。どちらも同じ Google アカウントでログイン
  • 両方で Samepaste が動いていること。スマホでは通知パネルにいつも表示されています

パスワード管理アプリのように、アプリが「機密」として扱うコピーはスマホから出ません。メッセージアプリが認証コードをそう扱う場合は届かないので、いつもどおり手で入力してください。
