Samepaste使いみち

スクショを、同じスマホのメモにそのまま

地図、予約画面、Wi-Fi のパスワード。残しておきたい画面はスクショして、メモには貼り付けるだけ。

Android
地図
メモ

土曜の展示

流れ

  1. スクリーンショットを撮る

    いつもの撮り方のままで。カメラで撮った写真も同じです。

  2. このスマホのクリップボードに入ります

    送信ボタンも、ギャラリーから選ぶ手間もありません。撮ったまま、元の画質で入っています。

  3. メモに貼り付ける

    画像を入れられるメモアプリで、入れたい場所を長押しして「貼り付け」。

必要なもの

  • Android 11 以上のスマホ1台。Google でログイン。PC はいりません
  • Samepaste の設定の「写真」で「スクリーンショット」をオン（カメラで撮った写真は「カメラの写真」）

ほかの端末に送らない設定にしていても、このスマホのクリップボードには入ります。Samepaste が見るのはカメラとスクリーンショットのフォルダだけなので、ほかのアプリが保存した画像は入りません。
