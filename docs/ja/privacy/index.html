プライバシー

更新日 2026-11-24

Samepaste は、コピーした内容を自分の端末どうしで移すアプリです。その内容が私やほかの誰かに届くことはありません。このページでは、端末の外に出るものをすべて挙げ、止める方法も書いています。

コピーした内容

コピーした文字や画像は自分の端末どうしを行き来するだけで、私が運営するサーバーには保存されません。パスワード管理アプリのコピーのように、アプリが「機密」として扱うものはそもそも送りません。

端末に残る履歴

以前のコピーをもう一度貼り付けられるように、各端末は端末どうしでやり取りしたものの履歴をそれぞれ保存します。初期設定は直近7日間・最大100件で、1日・7日・30日と、50件・100件・500件から選べます。古いものは自動で削除され、設定の「今すぐ消去」でその端末の履歴を空にできます。履歴は自分の端末にだけ残り、私に送られることも、サーバーに保存されることもありません。

写真やスクリーンショットを文字で検索できるように、各端末がその中の文字を端末内で読み取ります（スマホとタブレットは充電中で画面がオンのときだけ、PC は Windows 標準の文字認識を使います）。読み取った文字は読み取った端末にだけ残り、ほかの端末に送ったり、統計や診断に含めたりしません。「機密」として扱われるコピーは履歴に残しません。

アプリの統計は、同意したときだけ

スマホアプリと PC 版は、使用状況の統計とクラッシュレポートを送るかどうかを一度だけたずねます。2つのボタンは同じ大きさで、どちらかが先に選ばれていることもありません。選ぶまでは何も送りません。設定からいつでも変えられ、オフにするとすぐに送信が止まり、まだ送っていない分は破棄します。

同意した場合に送るのは、下の表のイベントだけです。どの項目も決まった単語か範囲で、自由な文章は含みません。回数はコピーのたびではなく、1日1回まとめて送ります。

名前タイミング項目
onboarding_step初回設定の各ステップが始まったときstep: notifications, photos, overlay, battery, login, stats, done
login_resultログインが終わったとき、または中断したときresult: ok, cancel, other_account, error
devices1日1回total, phones, tablets, pcs: 0–9, 10+
daily_usage1日1回、前日の分text_sent, image_sent, photo_auto, received: 0, 1–5, 6–20, 21–50, 51–100, 100+; delay_p50, delay_p90: ~0.5s, ~1s, ~2s, ~5s, 5s+; relay_share: 0, ~25%, ~50%, ~75%, 100%
problem画面に問題が表示されたときkind: other_account, battery_restricted, login_expired, blocked_by_rules, relay_only, offline_long
plan_eventそれが起きたときkind: limit_reached, trial_started, device_resting, paywall_opened, purchase_done, restore_done; from: notification, tile, home, settings, pc_window
feature_used1日1回、使った機能だけname: history, search, pin, send_now, send_mode_auto, send_mode_button, send_mode_off, receive_off, full_auto
app_error捕捉したエラー（Windows）where: モジュール名; code: 決まったエラー名

統計で送らないもの：コピーした内容、その正確な長さやサイズ、画像の中の文字、端末名、Google アカウントやメールアドレス、電話番号、正確な位置情報（GPS や住所）、広告 ID、エラーメッセージの文章。クラッシュレポートに含まれるのは、どこで落ちたかとその種類だけです。Google は接続の IP アドレスからおおよその国と地域を推定しますが、IP アドレスは保存しません。Google Analytics の詳細な位置情報と端末データの収集は、すべての地域でオフにしています。

Firebase が自動で記録するもの

Android のみで、統計の送信を選んだあとだけです（確認の前や「送らない」を選んだ場合、Firebase の収集そのものがオフです）。私たちのコードが選ぶものではなく Firebase Analytics が付ける記録で、コピーした内容は含まれません。画面名の自動記録（screen_view）はオフにしています。

名前タイミング含まれるもの
first_openアプリを初めて開いたときFirebase の標準項目（アプリのバージョン、時刻）
session_startアプリを使い始めたときセッション番号
user_engagementアプリを使っているあいだ画面に表示していた時間（ms）
in_app_purchaseGoogle Play で Pro を購入したとき商品 ID、名前、価格、通貨（カード情報は含まれません）

このサイトの統計

アクセス解析がオンのとき（下の「オフにする方法」を参照）、このサイトは Google Analytics 4 で次のものを数えます。値はすべて下の一覧にある決まった言葉だけで、入力やコピーした内容は含まれません。トップページでは使いみちのシーンをカルーセルで見せています。訪問ごとに最初に表示するシーンをランダムに選び、そのシーン ID を first_scene としてこれらの記録に付けます。

scene_view使いみちのシーンの半分以上が画面の中央に 1 秒より長く表示されたとき（シーンごとに 1 回）。トップページのカルーセルでは、手前のシーンだけscene: トップページでは lecture, address, search, otp, one_phone; 使いみちのページでは otp, photo_ai, link, tablet_note, one_phone

Google Analytics は、ブラウザ、端末の種類、接続から推定したおおよその国と都市も記録します。IP アドレスは保存しません。広告機能、Google シグナル、広告のパーソナライズはオフにしてあり、広告データは除外しています。ランダムな ID を入れた _ga Cookie は、統計を許可しているあいだだけ設定されます。最初に確認する地域では、許可するまで Google から何も読み込みません。

受け取る相手

  • Google（Firebase Analytics、Crashlytics、Google Analytics 4）：上に書いたアプリ、PC 版、このサイトの統計とクラッシュレポートを、まとめて受け取ります。
  • Google Play：スマホで購入したときの購入情報。支払いは Google が処理します。
  • Paddle：PC で購入したときの購入情報。Paddle が販売者として、支払い、税金、領収書を担当します。
  • RevenueCat：何を買ったかの記録。Google アカウントそのものではなく、そこから作った値にひもづけて保存し、そのアカウントでログインしている全部の端末で Pro を使えるようにします。
  • Tailscale Inc.（アプリ内で端末どうしをつなぐ接続サービス）：端末がログインするときに Google アカウントのメールアドレス、端末名、IP アドレスを受け取り、自分の端末どうしが互いを見つけられるようにします。コピーした内容は受け取りません。端末どうしは暗号化して直接つながり、直接つながらないときは Tailscale の中継を通りますが、暗号化されたままなので内容は読めません。
  • GitHub：このサイトとダウンロードファイルを置いている場所です。ほかのウェブサーバーと同じく、ページを開いたりファイルをダウンロードしたりするときに IP アドレスとブラウザの情報を受け取り、GitHub 自身のプライバシーステートメントに従って扱います。このサイトのフォントもここから配信しているので、フォントサービスに訪問が知られることはありません。
  • Google（Google フォーム）：ベータ特典のために残したメールアドレス。特典コードを一度送るためだけに使います。

保存期間

統計は14か月保存したあと削除します。購入記録は、購入と法律に必要な期間、Google Play、Paddle、RevenueCat が保管します。

公開のお知らせをメールで頼まれた場合、そのアドレスはその返信1回にだけ使い、返信したあとはそのメールを削除します。

ベータ特典のために残したメールアドレスは、コードを送ったあと削除します。

オフにする方法

  • アプリと PC 版：設定の統計スイッチ。
  • このサイト：各ページのいちばん下にあるボタン。選択はこのブラウザに保存され、オフにしたあとは統計のリクエストを一切送りません。
  • EU と EEA（欧州経済領域）、英国、スイスでは、またブラウザがどの地域にいるかを伝えない場合も、最初に確認し、許可するまで Google Analytics から何も読み込みません。
