Install the open beta

Samepaste is in open beta: free, downloaded from this site rather than a store for now. Install it on your Windows PC and on your Android phone or tablet, then sign in with the same Google account on each.

Windows PC

Windows 10 or 11

Download for Windows
File
Samepaste-0.8.0-beta.1.exe
SHA-256
643c44801da2eb895424561beaadf9f5133b7ae0b5dfa33b2e20540d6103fdbb

  1. Download the installer

    Use the button above. The file comes from this project’s GitHub releases.

  2. Get past SmartScreen

    The beta isn’t code-signed yet, so Windows may say ‘Windows protected your PC’. Click ‘More info’, check that the file is Samepaste, then click ‘Run anyway’.

  3. Install and sign in

    Follow the installer, then sign in with Google.

Android phone or tablet

Android 11 or later

Get the Android APK
File
Samepaste-0.8.0-beta.1.apk
SHA-256
5fa6e273afc4d0bdbc3ee435fbfec69b49cc401337b91479b229b03c391c7b90

  1. Download the APK

    Open this page on the phone or tablet and use the button above.

  2. Allow installs from your browser

    Open the downloaded file. If Android says it can’t install unknown apps from this source, tap ‘Settings’, turn on ‘Allow from this source’, and go back.

  3. Install and sign in

    Tap ‘Install’. If Google Play Protect warns about an app it doesn’t know, choose to install anyway. Then sign in with the same Google account as on your PC.

Menu names differ a little between phone makers.

To check a download, compare its SHA-256 with the one above. On Windows: Get-FileHash in PowerShell.
