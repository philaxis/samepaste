How it goes

  1. Copy the code on the phone

    Long-press the code and tap Copy, or tap the copy button next to it.

  2. It reaches the PC by itself

    Within seconds with the basic setup, the moment you copy with Full auto on.

  3. Press Ctrl+V on the PC

    Click the code box and paste. No retyping, no typos.

What you need

  • A Windows 10 or 11 PC and an Android 11+ phone on the same Google account
  • Samepaste running on both

Copies marked sensitive stay on the phone. If your messages app marks codes that way, type it as usual.
