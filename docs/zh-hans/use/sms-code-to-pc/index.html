怎么用

  1. 在手机上复制验证码

    在短信里长按验证码，点“复制”；或者点短信应用在验证码旁边显示的复制按钮。

  2. 它会自己跑到电脑上

    Samepaste 发现你复制了内容，就会把它放进电脑的剪贴板。基础设置下可能要几秒钟；在设置里打开“全自动”，复制的那一刻就过去了。

  3. 在电脑上按 Ctrl+V

    点一下验证码输入框，粘贴。没人手动输入，也就没人会输错。

需要准备

  • 一台 Windows 10 或 11 电脑和一部 Android 11 及以上的手机，登录同一个 Google 账号
  • 两边都运行着 Samepaste；在手机上，它常驻在通知栏里

被应用标记为敏感的复制内容（密码管理器就会这样做）会留在手机上。如果你的短信应用也这样标记验证码，验证码就不会传过去，那就照常手动输入吧。
