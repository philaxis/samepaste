电脑上复制的链接，在手机上打开

一份菜谱，一张地图，一篇留着坐车时看的长文。链接在电脑上，你想在手机上看。

怎么用

  1. 在电脑上复制网址

    在地址栏或网页里选中它，按 Ctrl+C。

  2. 它已经在手机的剪贴板里

    手机上什么都不用点。在我自己的电脑和手机上，这只用了 0.1 到 0.3 秒。

  3. 粘贴到手机浏览器里

    点地址栏，长按后选“粘贴”；或者点输入法提示的刚复制的链接。

需要准备

  • 电脑和手机登录同一个 Google 账号
  • 什么网络都行：手机用流量，电脑连家里的 Wi‑Fi 也可以

这只是复制和粘贴：Samepaste 不会自己在另一台设备上打开链接。
