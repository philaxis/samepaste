Samepaste用法

用手机拍下题目，在笔记本上问 ChatGPT

题目在纸上，ChatGPT 在笔记本上。手机摄像头就是两者之间最短的路。

Android
相机
Windows 笔记本
ChatGPT
第 3 题一步一步讲给我听
CtrlV

怎么用

  1. 拍照

    照常用手机自带的相机应用拍。截图也一样。

  2. 它会进到笔记本的剪贴板

    没有发送按钮。开着自动发送时，照片会以原图画质进到每台设备的剪贴板。

  3. 粘贴到 ChatGPT

    点一下输入框，按 Ctrl+V，写上你的问题，发送。

需要准备

  • 在手机 Samepaste 设置的“照片”里打开“相机照片”（截图是“截图”）
  • 手机和笔记本登录同一个 Google 账号

Samepaste 只看相机和截图文件夹，所以其他应用保存的图片不会自己传过去。
