安装公开测试版

Samepaste 正在公开测试：免费，目前从本站下载，而不是应用商店。在 Windows 电脑和 Android 手机或平板上安装，然后在每台设备上用同一个 Google 账号登录。

Windows 电脑

Windows 10 或 11

下载 Windows 版
文件
Samepaste-0.8.1-beta.7.exe
SHA-256
c14649884b5607f3c46779a6f8fc682994e655434c791bddeee8d5253aff6a83

  1. 下载安装程序

    用上面的按钮下载。文件来自本项目在 GitHub 上的发布页面。

  2. 通过 SmartScreen

    测试版还没有代码签名，Windows 可能会提示“Windows 已保护你的电脑”。点“更多信息”，确认文件是 Samepaste，再点“仍要运行”。

  3. 打开并登录

    打开下载的文件，Samepaste 窗口会打开并告诉你接下来做什么。用 Google 登录。

电脑上在用测试版 1–5？这次请下载并打开这个文件一次，登录和记录都会保留。从测试版 6 起，有新版本时 Samepaste 会提醒你，点“更新”即可更新。

Android 手机或平板

Android 11 及以上

下载 Android APK

Samepaste-0.8.1-beta.7.apk

  1. 下载 APK

    在手机或平板上打开本页，用上面的按钮下载。

  2. 允许从浏览器安装

    打开下载的文件。如果 Android 提示无法安装来自此来源的未知应用，点“设置”，打开“允许来自此来源的应用”，再返回。

  3. 安装并登录

    点“安装”。如果 Google Play 保护机制提示这是它不认识的应用，选择仍然安装。然后用和电脑上相同的 Google 账号登录。

不同手机厂商的菜单名称会略有不同。

要核对下载的文件，把它的 SHA-256 和上面的值对比。在 Windows 上，可以用 PowerShell 的 Get-FileHash 查看。
