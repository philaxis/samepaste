隐私政策

更新于 2026-11-19

Samepaste 在你自己的设备之间传递你复制的内容。这些内容永远不会到我或任何人手里。本页列出所有会离开你设备的东西，以及怎么让它停下。

你复制的内容

复制的文字和图片只在你自己的设备之间传递，从不保存在我运营的服务器上。被应用标记为敏感的复制内容，比如密码管理器里的，根本不会发送。

保存在你设备上的历史记录

为了让你能再次粘贴以前复制的内容，每台设备都会各自保存设备之间传递过的内容的历史记录：默认保留最近 7 天、最多 100 条（可以选择 1 天、7 天或 30 天，以及 50、100 或 500 条）。更早的条目会自动删除，在设置里点“立即清空”可以清空这台设备的历史记录。历史记录只留在你的设备上，不会发给我，也不会存到服务器上。

为了能按文字搜索照片和截图，每台设备会自己识别其中的文字（手机和平板只在充电且屏幕亮着时进行；电脑使用 Windows 自带的文字识别）。识别出的文字只留在识别它的那台设备上，不会发送到你的其他设备，也不会放进统计或诊断数据。标记为敏感的复制内容不会保存在历史记录里。

应用统计，需你同意

手机应用和电脑程序会问你一次，是否发送使用统计和崩溃报告。两个按钮一样大，也没有替你预先选好。你做出选择之前，什么都不会发送。你随时可以在设置里更改；关闭后立即停止发送，还没发出的内容也会丢弃。

如果你同意，只会发送下面这些事件。每个字段都是固定的词或区间，绝不是自由文本；计数每天发送一次，而不是每复制一次就发一次。

名称何时字段

统计中绝不发送：你复制的内容、它的确切长度或大小、图片里的文字、设备名称、你的 Google 账号或邮箱地址、电话号码、精确位置（GPS 或地址）、广告 ID、错误信息的文字。崩溃报告只包含崩溃发生的位置和类型。Google 会根据连接的 IP 地址大致推测国家和地区，但不保存 IP 地址；Google Analytics 的精细位置和设备数据收集在所有地区都已关闭。

Firebase 自动记录的内容

仅限 Android，且只在你选择发送统计之后（在询问之前或选择“不发送”时，Firebase 的收集本身就是关闭的）。这些记录由 Firebase Analytics 自己添加，不是我们的代码选择的，也不包含你复制的内容。界面名称的自动记录（screen_view）已关闭。

名称何时包含什么
first_open第一次打开应用时Firebase 的标准字段（应用版本、时间）
session_start开始使用应用时会话编号
user_engagement使用应用期间停留在界面上的时间（毫秒）
in_app_purchase在 Google Play 购买专业版时商品 ID、名称、价格和币种（不含银行卡信息）

访问统计开启时（见下文），本站用 Google Analytics 4 统计以下内容。所有值都只是下面列表中的固定词语，不含你输入或复制的任何内容。首页用轮播展示使用场景；每次访问会随机选定起始场景，并把这个场景的 ID 作为 first_scene 附在这些事件上。

Google Analytics 还会记录浏览器、设备类型，以及根据网络连接推测的大致国家和城市；它不保存 IP 地址。广告功能、Google 信号和广告个性化都已关闭，广告数据也会被隐去。存有随机 ID 的 _ga Cookie 只在你允许统计期间才会设置。在会先征求同意的地区，你允许之前本站不会从 Google 加载任何内容。

谁会收到什么

  • Google（Firebase Analytics、Crashlytics、Google Analytics 4）：上面提到的应用、电脑程序和本站的统计与崩溃报告，集中在一处。
  • Google Play：你在手机上购买时的购买记录。付款由 Google 处理。
  • Paddle：你在电脑上购买时的购买记录。Paddle 作为销售方，负责收款、税费和收据。
  • RevenueCat：你买了什么的记录。它记在一个由你的 Google 账号生成的值下面，而不是账号本身，让用这个账号登录的所有设备都能使用专业版。
  • Tailscale Inc.（应用内用来连接设备的连接服务）：设备登录时接收你的 Google 账号邮箱、设备名称和 IP 地址，让你的设备能互相找到。不接收你复制的内容：设备之间加密直连；无法直连时会经过 Tailscale 中继，但内容仍然加密，对方无法读取。
  • GitHub：托管本网站和下载文件。和任何网页服务器一样，你打开页面或下载文件时，它会收到你的 IP 地址和浏览器信息，并按 GitHub 自己的隐私声明处理。本站的字体也由它提供，所以没有任何字体服务能看到你的访问。
  • Google（Google 表单）：为领取测试版福利留下的邮箱地址，只用来发送一次福利兑换码。

保存多久

统计数据保存 14 个月后删除。购买记录由 Google Play、Paddle 和 RevenueCat 按购买和法律要求的期限保存。

如果你发邮件让我在上线时通知你，你的邮箱地址只用于那一封回信；回信之后我会删除这些邮件。

为测试版福利留下的邮箱地址，在发出兑换码后删除。

如何关闭

  • 应用和电脑程序：设置里的统计开关。
  • 本网站：每个页面底部的按钮。你的选择保存在这个浏览器里；关闭统计后，不会再发送任何统计请求。
  • 在欧盟和欧洲经济区、英国、瑞士，以及浏览器没有告知所在地区时，本站会先征求同意，在你允许之前不会从 Google Analytics 加载任何内容。
