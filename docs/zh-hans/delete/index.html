删除 Samepaste 数据

更新于 2026-11-19

本页适用于 philaxis 开发的剪贴板应用 Samepaste，包括 Android 手机和平板版（Google Play）以及 Windows 电脑版。这里写了如何删除应用产生的数据，以及删除后还会保留什么。

Samepaste 没有自己的账号：不用注册，没有密码，你复制的内容也不会保存在任何服务器上。不过，用 Google 登录时，应用内置的连接服务（Tailscale）会为你建立一个账号，让你的设备互相找到。第 3 步会删除它。

删除步骤

  1. 在每台设备上清空历史记录并退出登录

    在 Samepaste 的设置里点“立即清空”，再点“清空”确认。这会删除这台设备上的历史记录，包括从图片中识别出的文字。然后在设置的“Google 账号”一栏退出登录。

  2. 卸载应用

    在每台手机、平板和电脑上卸载 Samepaste。应用留在设备上的一切，包括设置，都会一并删除。

  3. 删除连接服务账号

    打开 Tailscale 管理控制台，用同一个 Google 账号登录。选择“Delete tailnet”，再点“Delete”确认，Tailscale Inc. 就会删除你的设备列表、设备名称和邮箱地址。以后如果再用这个账号登录 Samepaste，会重新建立一个账号。

  4. 其余数据请发邮件删除

    从任意邮箱发邮件到 philaxis.dev@gmail.com，告诉我你登录时用的 Google 账号。不需要安装应用。我会删除你的购买记录和你发给我的邮件，然后回复你。

如果你自己也在同一个 Google 账号下使用 Tailscale，“Delete tailnet”会把你自己的网络一起删除。这时请在 Machines 页面只移除装有 Samepaste 的设备。

会删除的数据

  • 设备上的历史记录和从图片中识别出的文字：点“立即清空”或卸载应用后，立即从该设备删除。
  • Tailscale Inc. 保存的设备名称、邮箱地址和 IP 地址：删除 tailnet 后从其服务器删除。据 Tailscale 说明，诊断日志和备份中的副本通常会在 60 天内自动消失。
  • RevenueCat 上的购买记录：收到你的邮件后删除。
  • 你发给我的邮件（包括这次请求）：回复后删除。为测试版福利留下的邮箱地址，在发出兑换码后删除。

会保留的数据和保留期限

  • 使用统计和崩溃报告（仅在你选择发送时）：只带有一个随机 ID，不含你的姓名、邮箱地址或 Google 账号，因此无法单独挑出某个人的数据来删除。14 个月后自动删除。
  • Google Play 和 Paddle 的购买和税务记录：由它们按法律要求的期限保存。
  • 你复制的内容：从不保存在服务器上，因此那里没有需要删除的内容。
