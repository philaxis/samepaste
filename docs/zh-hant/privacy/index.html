隱私權政策

更新於 2026-11-19

Samepaste 在你自己的裝置之間傳送你複製的內容。這些內容不會傳到我或任何人手上。這一頁列出所有會離開你裝置的資料，以及如何停止。

你複製的內容

複製的文字和圖片只在你自己的裝置之間傳送，從不儲存在我架設的伺服器上。像密碼管理工具那樣被 App 標記為敏感的內容，完全不會傳送。

留在你裝置上的紀錄

為了讓你能再次貼上以前複製的內容，每台裝置都會各自保存裝置之間傳送過的紀錄：預設保留最近 7 天、最多 100 筆（可以選擇 1 天、7 天或 30 天，以及 50、100 或 500 筆）。較舊的項目會自動刪除，在設定裡按「立即清除」就能清空這台裝置的紀錄。紀錄只留在你的裝置上，不會傳給我，也不會存到伺服器上。

為了能用文字搜尋照片和螢幕截圖，每台裝置會自己辨識其中的文字（手機和平板只在充電中且螢幕開著時進行；電腦使用 Windows 內建的文字辨識）。辨識出的文字只留在辨識它的那台裝置上，不會傳到你的其他裝置，也不會放進統計或診斷資料。標記為敏感的複製內容不會保存在紀錄裡。

App 統計，只在你同意時

手機 App 和電腦程式會問你一次要不要傳送使用統計和當機報告，兩個按鈕一樣大，也沒有預先幫你選好。在你選擇之前，什麼都不會傳送。你隨時可以在設定裡更改；關閉後會立刻停止傳送，尚未送出的資料也會丟棄。

如果你同意，只會傳送下面列出的事件。每個欄位都是固定的詞或範圍，絕不是自由輸入的文字；次數是一天傳一次，而不是每複製一次就傳。

Firebase 自動記錄的內容

僅限 Android，而且只在你選擇傳送統計之後（詢問之前或選擇「不傳送」時，Firebase 的收集本身就是關閉的）。這些紀錄由 Firebase Analytics 自己加上，不是我們的程式碼選的，也不包含你複製的內容。畫面名稱的自動記錄（screen_view）已關閉。

Google Analytics 也會記錄瀏覽器、裝置類型，以及從連線推估出的大致國家和城市；它不會保存 IP 位址。廣告功能、Google 信號和廣告個人化都已關閉，廣告資料也會遮蔽。存有隨機 ID 的 _ga Cookie 只在你允許統計時才會設定。在會先詢問的地區，你允許之前網站不會從 Google 載入任何內容。

誰會收到什麼

  • Google（Firebase Analytics、Crashlytics、Google Analytics 4）：上述 App、電腦程式和這個網站的統計與當機報告，集中在同一處。
  • Google Play：你在手機上購買時的購買紀錄。付款由 Google 處理。
  • Paddle：你在電腦上購買時的購買紀錄。Paddle 是登記的賣方，負責付款、稅金和收據。
  • RevenueCat：你買了什麼的紀錄，以一個由你的 Google 帳戶產生的值來歸檔，而不是帳戶本身，讓用這個帳戶登入的所有裝置都能使用 Pro。
  • Tailscale Inc.（App 內用來連接裝置的連線服務）：裝置登入時接收你的 Google 帳戶電子郵件、裝置名稱和 IP 位址，讓你的裝置能互相找到。不接收你複製的內容：裝置之間加密直連；無法直連時會經過 Tailscale 中繼，但內容仍然加密，對方無法讀取。
  • GitHub：託管這個網站和下載檔案。和任何網頁伺服器一樣，你開啟頁面或下載檔案時，它會收到你的 IP 位址和瀏覽器資訊，並依 GitHub 自己的隱私權聲明處理。這個網站的字型也由它提供，所以字型服務不會知道你的造訪。
  • Google（Google 表單）：為了測試版福利留下的電子郵件地址，只用來寄一次福利兌換碼。

保存多久

統計資料保存 14 個月後刪除。購買紀錄由 Google Play、Paddle 和 RevenueCat 依購買和法律要求的期間保存。

如果你寫信要求在推出時通知你，你的電子郵件地址只會用在那一封回信；回信之後我就會刪除這些信。

為了測試版福利留下的電子郵件地址，寄出兌換碼後就會刪除。

如何關閉

  • App 和電腦程式：設定裡的統計開關。
  • 這個網站：每個頁面最下方的按鈕。你的選擇會記在這個瀏覽器裡，關閉統計後就不會再送出任何統計請求。
  • 在歐盟和歐洲經濟區、英國、瑞士，以及瀏覽器沒有告知所在地區時，網站會先詢問你，在你允許之前不會從 Google Analytics 載入任何內容。
