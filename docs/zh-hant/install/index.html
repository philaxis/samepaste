安裝公開測試版

Samepaste 目前是公開測試版：免費，暫時從這個網站下載，而不是應用程式商店。在 Windows 電腦和 Android 手機或平板上安裝，再於每台裝置用同一個 Google 帳戶登入。

Windows 電腦

Windows 10 或 11

下載 Windows 版
檔案
Samepaste-0.8.0-beta.5.exe
SHA-256
7fff575093267809483b92553542c683879c75c62f13cb0da0e1ebaf6642c7be

  1. 下載安裝程式

    用上面的按鈕下載。檔案來自這個專案在 GitHub 上的發布頁面。

  2. 通過 SmartScreen

    測試版還沒有程式碼簽章，Windows 可能會顯示「Windows 已保護您的電腦」。按「其他資訊」，確認檔案是 Samepaste，再按「仍要執行」。

  3. 安裝並登入

    依照安裝程式的步驟完成，再用 Google 登入。

Android 手機或平板

Android 11 以上

下載 Android APK
檔案
Samepaste-0.8.0-beta.5.apk
SHA-256
9b94516d2c034003429d6dd9104a657f62ebdf25654e030cc0a33a663f52e917

  1. 下載 APK

    在手機或平板上開啟這個頁面，用上面的按鈕下載。

  2. 允許從瀏覽器安裝

    開啟下載的檔案。如果 Android 顯示無法安裝來自這個來源的不明應用程式，請點「設定」，開啟「允許這個來源的應用程式」，再返回。

  3. 安裝並登入

    點「安裝」。如果 Google Play 安全防護警告這是它不認識的應用程式，選擇仍要安裝。接著用和電腦相同的 Google 帳戶登入。

不同手機品牌的選單名稱會有些差異。

要確認下載的檔案，請把它的 SHA-256 和上面的值比對。在 Windows 上，可以用 PowerShell 的 Get-FileHash 查看。
