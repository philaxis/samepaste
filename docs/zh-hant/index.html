更多用法

  • 手機收到的驗證碼，直接貼進電腦的登入畫面

    從簡訊複製驗證碼，在電腦上按 Ctrl+V。不用再盯著六位數字，在另一個螢幕上一個一個打。

  • 用手機拍下題目，在筆電上問 ChatGPT

    拍完照，它已經在筆電的剪貼簿裡了。貼到 ChatGPT 就能問。

  • 在電腦上複製的連結，用手機打開

    在電腦上複製網址，貼到手機的瀏覽器。不用再用 LINE 把連結傳給自己了。

  • 手機拍的照片，直接放進平板的筆記

    在平板上做筆記，需要白板或投影片的內容？用手機拍下來，貼進筆記就好。

  • 卡住的時候

    手機和電腦之間的複製貼上失靈時，可以一步一步照著做的解決方法。不管你用哪個 App，大多都適用。
