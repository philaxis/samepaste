Samepaste使用情境

用手機拍下題目，在筆電上問 ChatGPT

題目在紙上，ChatGPT 在筆電上。兩者之間最短的路，就是手機相機。

Android
相機
Windows 筆電
ChatGPT
教我第 3 題怎麼解
CtrlV

怎麼做

  1. 拍照

    跟平常一樣用手機內建的相機 App。螢幕截圖也一樣。

  2. 照片進到筆電的剪貼簿

    沒有傳送按鈕。只要開著自動傳送，照片就會以原始畫質進到每台裝置的剪貼簿。

  3. 貼到 ChatGPT

    點一下輸入框，按 Ctrl+V，打上你的問題再送出。

需要準備

  • 在手機 Samepaste 設定的「照片」裡打開「相機照片」（螢幕截圖是「螢幕截圖」）
  • 手機和筆電登入同一個 Google 帳戶

Samepaste 只看相機和螢幕截圖資料夾，所以其他 App 存下的圖片不會自己傳過去。
