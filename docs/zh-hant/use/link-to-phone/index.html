Samepaste使用情境

在電腦上複製的連結，用手機打開

食譜、地圖、想在公車上讀的長文。連結在電腦上，你想在手機上看。

Windows 電腦
記事本

路上要看的

zh.wikipedia.org/zh-tw/剪貼簿

然後是週六的地圖

Android
瀏覽器

zh.wikipedia.org/zh-tw/剪貼簿

貼上
zh.wikipedia.org/zh-tw/剪貼簿

怎麼做

  1. 在電腦上複製網址

    在網址列或網頁裡選取網址，按 Ctrl+C。

  2. 它已經在手機的剪貼簿裡

    手機上什麼都不用點。在我自己的電腦和手機上，這只花了 0.1 到 0.3 秒。

  3. 貼到手機的瀏覽器

    點一下網址列，長按後選「貼上」，或直接點鍵盤建議的已複製連結。

需要準備

  • 電腦和手機登入同一個 Google 帳戶
  • 什麼網路都行：手機用行動數據、電腦連家裡的 Wi‑Fi 也可以

這是複製貼上：Samepaste 不會自己在另一台裝置上打開連結。
