Samepaste使用情境

手機收到的驗證碼，直接貼進電腦的登入畫面

你在電腦上登入，驗證碼卻傳到手機。在那邊複製，在這邊貼上。

怎麼做

  1. 在手機上複製驗證碼

    在簡訊裡長按驗證碼再點「複製」，或點簡訊 App 在驗證碼旁邊顯示的複製按鈕。

  2. 它會自己傳到電腦

    Samepaste 發現你複製後，會把內容放進電腦的剪貼簿。基本設定下可能要等幾秒；在設定裡開啟「全自動」，複製的瞬間就會傳過去。

  3. 在電腦上按 Ctrl+V

    點一下驗證碼欄位再貼上。沒有人重打，就沒有人打錯。

需要準備

  • Windows 10 或 11 電腦，加上 Android 11 以上的手機，兩邊登入同一個 Google 帳戶
  • 兩邊都開著 Samepaste；在手機上它會常駐在通知欄

像密碼管理工具那樣被 App 標記為敏感的內容，會留在手機上。如果你的簡訊 App 也這樣標記驗證碼，驗證碼就不會傳過去，這時請照平常那樣自己輸入。
