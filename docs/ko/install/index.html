오픈 베타 설치

Samepaste는 오픈 베타예요. 무료이고, 지금은 스토어 대신 이 사이트에서 받아요. Windows PC와 안드로이드 폰·태블릿에 깔고, 기기마다 같은 구글 계정으로 로그인하면 돼요.

Windows PC

Windows 10·11

Windows용 다운로드
파일
Samepaste-0.8.0-beta.1.exe
SHA-256
643c44801da2eb895424561beaadf9f5133b7ae0b5dfa33b2e20540d6103fdbb

  1. 설치 파일 받기

    위 단추로 받아요. 파일은 이 프로젝트의 GitHub 릴리스에서 와요.

  2. SmartScreen 넘기기

    베타는 아직 코드 서명이 없어서 ‘Windows의 PC 보호’ 창이 뜰 수 있어요. ‘추가 정보’를 눌러 파일이 Samepaste인지 보고 ‘실행’을 눌러요.

  3. 설치하고 로그인

    설치 창을 따라가고, 구글로 로그인해요.

파일
Samepaste-0.8.0-beta.1.apk
SHA-256

  1. APK 받기

    폰이나 태블릿에서 이 쪽을 열고 위 단추로 받아요.

  2. 브라우저에서 설치 허용

    받은 파일을 열어요. ‘이 출처의 알 수 없는 앱을 설치할 수 없다’는 창이 뜨면 ‘설정’을 눌러 ‘이 출처 허용’을 켜고 돌아와요.

  3. 설치하고 로그인

    ‘설치’를 눌러요. Google Play 프로텍트가 모르는 앱이라고 알리면 그래도 설치를 골라요. 그다음 PC와 같은 구글 계정으로 로그인해요.

메뉴 이름은 폰 만든 회사마다 조금씩 달라요.

받은 파일이 맞는지 보려면 SHA-256을 위 값과 견줘 보세요. Windows에서는 PowerShell의 Get-FileHash로 볼 수 있어요.
