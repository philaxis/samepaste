오픈 베타 설치

Samepaste는 오픈 베타예요. 무료이고, 지금은 스토어 대신 이 사이트에서 받아요. Windows PC와 안드로이드 폰·태블릿에 깔고, 기기마다 같은 구글 계정으로 로그인하면 돼요.

Windows PC

Windows 10·11

Windows용 다운로드

Samepaste-0.8.1-beta.7.exe

  1. 설치 파일 받기

    위 단추로 받아요. 파일은 이 프로젝트의 GitHub 릴리스에서 와요.

  2. SmartScreen 넘기기

    베타는 아직 코드 서명이 없어서 ‘Windows의 PC 보호’ 창이 뜰 수 있어요. ‘추가 정보’를 눌러 파일이 Samepaste인지 보고 ‘실행’을 눌러요.

  3. 열고 로그인

    받은 파일을 열면 Samepaste 창이 열리고 할 일을 보여 줘요. 구글로 로그인해요.

PC에서 베타 1~5판을 쓰고 있다면 이번 한 번만 이 파일을 받아 열어 주세요. 로그인과 기록은 그대로 이어져요. 베타 6판부터는 새 판이 나오면 Samepaste가 알려 주고, ‘업데이트’를 누르면 바뀌어요.

  1. APK 받기

    폰이나 태블릿에서 이 쪽을 열고 위 단추로 받아요.

  2. 브라우저에서 설치 허용

    받은 파일을 열어요. ‘이 출처의 알 수 없는 앱을 설치할 수 없다’는 창이 뜨면 ‘설정’을 눌러 ‘이 출처 허용’을 켜고 돌아와요.

  3. 설치하고 로그인

    ‘설치’를 눌러요. Google Play 프로텍트가 모르는 앱이라고 알리면 그래도 설치를 골라요. 그다음 PC와 같은 구글 계정으로 로그인해요.

메뉴 이름은 폰 만든 회사마다 조금씩 달라요.

받은 파일이 맞는지 보려면 SHA-256을 위 값과 견줘 보세요. Windows에서는 PowerShell의 Get-FileHash로 볼 수 있어요.

오픈 베타라는 것

  • 무료예요. 베타 동안은 아무것도 팔지 않아요.
  • 정식 출시 전까지 기능, 생김새, 한도가 바뀌거나 고장 날 수 있어요.
  • 베타는 2026년 12월 31일에 끝나요. 그 뒤에도 앱은 멈추지 않고 무료판 한도로 계속 쓸 수 있고, 베타를 쓰신 분께는 유료판 3개월을 저절로 드려요. 베타 1~5판은 이걸 모르니 그 전에 6판 이상으로 바꿔 주세요.
  • 고장이나 바라는 점은 GitHub 이슈에 남기거나 philaxis.dev@gmail.com으로 메일 주세요.
