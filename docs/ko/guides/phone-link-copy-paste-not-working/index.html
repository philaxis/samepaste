Samepaste문제 해결

휴대폰과 연결에서 복사 붙여넣기가 안 될 때 먼저 볼 것

안드로이드, Windows고친 날 2026-11-20

PC의 ‘휴대폰과 연결’에 문자와 사진은 잘 뜨는데, 폰에서 복사한 게 PC에서 안 붙거나 PC에서 복사한 게 폰에서 안 붙어요. 고장이 아닐 때가 많아요. 휴대폰과 연결의 여러 기능 가운데 복사·붙여넣기만은 일부 폰에서만 되거든요. 마이크로소프트 도움말의 그 칸 첫 줄에 이렇게 적혀 있어요.

“This is applicable for Surface Duo and select Samsung and HONOR and OPPO and ASUS and vivo and Xiaomi devices.”

Microsoft 지원, 휴대폰과 연결 (영어 원문)

마이크로소프트가 알려 주는 순서

  1. 내 폰이 목록에 있는지 봐요

    마이크로소프트가 밝힌 지원 폰은 Surface Duo, One UI 2.1 이상인 삼성 폰, 그리고 일부 HONOR·OPPO(OnePlus·Realme 포함)·ASUS·vivo·Xiaomi 폰이에요. 갤럭시는 설정 › 휴대전화 정보 › 소프트웨어 정보에서 One UI 버전을 볼 수 있어요. 목록에 없는 폰이라면 마이크로소프트가 이 기능을 지원하지 않는 거라서, 아래 두 단계를 해도 달라지지 않아요.

  2. 휴대폰과 연결에서 기능을 켜요

    PC에서 휴대폰과 연결을 열고 설정 › 기능 › 장치 간 복사 및 붙여넣기로 가요. 휴대폰과 PC 사이에 복사해 붙여 넣은 콘텐츠에 이 앱이 접근하고 전송하도록 허용하는 스위치가 켜져 있어야 해요.

  3. 두 앱을 닫았다가 다시 열어요

    PC의 휴대폰과 연결, 폰의 Windows와 연결 앱을 둘 다 닫고 다시 열어요. PC에 최근 문자·사진·알림이 보이면 연결은 된 거라 복사·붙여넣기도 다시 될 거예요. 그래도 안 되면 PC를 다시 시작해 봐요.

그 밖에 알아 둘 것

아주 긴 글은 허용량을 넘으면 넘어가지 않으니 나눠서 복사해요. 넘어가는 건 글자와 이미지뿐이고, 1MB가 넘는 이미지는 크기가 줄어요.

와이파이가 아닐 때는 폰의 Windows와 연결 설정에서 ‘모바일 데이터 사용’이 켜져 있어야 해요. 마이크로소프트 엣지를 쓴다면 최신 버전으로 올리라고도 해요. 모두 마이크로소프트의 휴대폰과 연결 도움말에 있는 내용이에요.

목록에 없는 폰이라면

목록에 있는 폰이면 휴대폰과 연결을 그대로 쓰세요. 이미 PC에 들어 있고 문자·전화·알림까지 가져와요. Samepaste는 클립보드만 해요.

목록에 없는 폰이라면 Samepaste가 복사·붙여넣기를 대신해요. 갤럭시든 아니든 안드로이드 11 이상 폰과 Windows 10·11 PC면 돼요. 한쪽에서 복사하고 다른 쪽에서 붙여 넣어요. 양쪽 다 되고, 폰으로 찍은 사진과 스크린샷도 원본 그대로 넘어가요.

  1. Samepaste

    2단계

    1. 폰에서 복사
    2. PC에서 Ctrl+V

휴대폰과 연결도, 마이크로소프트 계정도 필요 없어요. 두 기기에 같은 구글 계정으로 로그인하면 끝이에요. 폰은 LTE, PC는 와이파이여도 돼요. 제 기기에서 재 보니 PC에서 복사한 글이 폰에 0.1~0.3초 만에 들어왔어요.

두 단계는 이 사이트에서 받은 안드로이드 앱 기준이에요. 구글 플레이 판에서는 폰에서 복사한 글을 보낼 때 빠른 설정의 ‘지금 보내기’를 한 번 더 눌러요.

Samepaste에 필요한 것

  • 안드로이드 11 이상 폰과 Windows 10·11 PC가 같은 구글 계정으로 로그인해 있어야 해요. 아이폰·아이패드·맥·리눅스는 안 돼요.
  • 다른 앱에서 복사한 글은, 이 사이트에서 받은 안드로이드 앱이 화면에서 손을 떼고 1초쯤 뒤에 스스로 알아채요. 폰에 따라 늦거나 놓칠 때가 있어서, 설정의 ‘복사 바로 알아채기’를 켜면 복사할 때마다 바로 잡아요. 구글 플레이 판은 다른 앱의 복사를 스스로 읽지 못해요. 복사한 뒤 빠른 설정의 ‘지금 보내기’ 타일을 누르면 가요.
  • 비밀번호 관리자처럼 앱이 민감하다고 표시한 복사는 복사한 기기에만 남아요.
  • 오픈 베타 동안은 기기 10대까지 무료예요.
