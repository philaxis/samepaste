Samepaste쓰는 곳

폰으로 문제를 찍으면, 노트북 ChatGPT에 바로

문제는 종이에 있고 ChatGPT는 노트북에 있어요. 둘 사이 가장 짧은 길은 폰 카메라예요.

Android
카메라
Windows 노트북
ChatGPT
3번 문제 풀이 과정을 알려 줘
CtrlV

이렇게 돼요

  1. 폰으로 찍어요

    평소 쓰는 카메라 앱 그대로요. 스크린샷도 똑같이 돼요.

  2. 노트북 클립보드에 들어가요

    보내기 단추가 없어요. 자동 보내기가 켜져 있으면 찍은 사진이 원본 화질 그대로 모든 기기 클립보드에 들어가요.

  3. ChatGPT에 붙여 넣어요

    입력 칸을 누르고 Ctrl+V, 궁금한 걸 적어 보내면 돼요.

필요한 것

  • 폰 Samepaste 설정의 ‘사진’에서 ‘카메라 사진’ 켜기. 스크린샷은 ‘스크린샷’
  • 폰과 노트북이 같은 구글 계정

Samepaste는 카메라와 스크린샷 폴더만 봐요. 다른 앱이 저장한 그림은 저절로 넘어가지 않아요.
