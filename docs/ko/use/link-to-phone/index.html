이렇게 돼요

  1. PC에서 주소를 복사해요

    주소창이나 글 속의 주소를 골라 Ctrl+C.

  2. 폰 클립보드에 들어가 있어요

    폰에서 누를 건 없어요. 제 PC와 폰에서는 0.1~0.3초 걸렸어요.

  3. 폰 브라우저에 붙여 넣어요

    주소창을 누르고 길게 눌러 ‘붙여넣기’, 아니면 키보드가 보여 주는 복사한 링크를 눌러요.

필요한 것

  • PC와 폰이 같은 구글 계정
  • 네트워크는 상관없어요. 폰은 LTE, PC는 집 와이파이여도 돼요

복사와 붙여넣기예요. Samepaste가 다른 기기에서 링크를 저절로 열지는 않아요.
