폰 스크린샷 한 장을 PC로: 일곱 가지 길, 누르는 횟수 비교

글쓴이 philaxis

폰 스크린샷 한 장을 PC의 ChatGPT에 넣는 데 카톡 나와의 채팅은 일곱 번, Quick Share는 여섯 번, Samepaste는 한 번 눌러요. 많이 쓰는 일곱 가지 길을 각 회사 도움말 순서대로 세어 표 하나에 모았습니다.

한 장에 몇 번

길누름누르는 순서필요한 것화질
세임페이스트(Samepaste)1PC에서 Ctrl+V안드로이드 11+ 폰, Windows 10·11 PC, 같은 구글 계정원본
휴대폰과 연결, 장치 간 복사3스크린샷 열기 › 그림 복사 › PC에서 Ctrl+V지원 폰만(One UI 2.1+ 갤럭시와 일부 HONOR·OPPO·ASUS·vivo·Xiaomi), Windows 10·111MB 넘으면 크기 조정
삼성 클립보드 공유3스크린샷 열기 › 그림 복사 › PC에서 Ctrl+V갤럭시 폰, Galaxy Connect를 깐 Windows 11 x64 PC, 같은 삼성 계정, 같은 와이파이, 블루투스도움말에 없음
파일 탐색기(Windows 11)5파일 탐색기 › 폰 › 스크린샷 폴더 › 찾기 › 끌어다 놓기Windows 11, 안드로이드 11+, Windows와 연결원본
구글 포토5 + 백업 기다림photos.google.com › 사진 고르기 › 더보기 › 다운로드 › 끌어다 놓기백업 켜기, 스크린샷 폴더도 백업백업 화질 설정 따름
Quick Share6스크린샷 열기 › 공유 › Quick Share › 내 PC › 다운로드 폴더 열기 › 끌어다 놓기64비트 Windows 10+, 블루투스, 같은 네트워크, 5m 안구글 도움말에 없음
카톡 나와의 채팅7스크린샷 열기 › 공유 › 카카오톡 › 나와의 채팅 › 보내기 › PC 카톡에서 열기 › 끌어다 놓기PC 카카오톡, 같은 카카오계정카톡 사진 화질 설정 따름

누름 하나를 2초로 어림하면 하루 10장에 Quick Share보다 약 100초, 카톡보다 약 120초 덜 들어요. 한 달 20일이면 33분, 40분이죠. 휴대폰과 연결이나 삼성 클립보드 공유가 되는 폰이라면 차이는 장당 4초쯤이에요.

횟수만큼 신경 쓰였던 게 연결이에요. 제가 휴대폰과 연결이나 삼성 플로우를 쓸 땐 자주 끊겨서, 붙여 넣기 전에 연결됐는지 계속 확인해야 했거든요. Samepaste는 끊겨도 혼자 다시 붙어서 제가 누를 건 없어요. 폰을 껐다 켜도 앱을 열 필요 없이 저절로 다시 붙고, 로그인은 180일마다 다시 합니다.

글자만 옮기는 앱들

Pushbullet과 KDE Connect는 클립보드로 글자만 옮겨요. KDE 문서에도 “This does not work with images though.”라고 적혀 있죠(KDE 문서). 그림은 파일로 보내야 해서 Quick Share처럼 여섯 번쯤 누르게 됩니다.
